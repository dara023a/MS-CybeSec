D+E // Deep Dive & Technical Notes

ANALYSIS NODE
D

Deep Dive Material

Traffic analysis dimulai dari baseline: apa yang normal? Setelah itu baru membandingkan pola scanning, request web mencurigakan, query DNS tidak biasa, atau percobaan SQLi/XSS di lab. Filter Wireshark membantu menyaring protocol, IP, port, atau HTTP. Wazuh membantu melihat log host dan alert. Tujuannya bukan hanya menemukan serangan, tetapi memahami bukti dan konteks.


Hubungan offensive dan defensive: recruit belajar memahami root cause, dampak, bukti teknis, serta cara mengubah temuan menjadi rekomendasi perbaikan.

Technical Notes

Tools:

  • Wireshark
  • Wazuh
  • VirtualBox
  • OWASP Juice Shop lokal
  • DVWA lokal

O // Textbook Chapter

DEEP MATERIAL NODE
FULL CHAPTER MODE

Wireshark dan Wazuh Part 1: Membaca Traffic sebagai Sinyal Keamanan

Bab ini membahas packet, PCAP, protocol, filtering, dan hubungan antara aktivitas ofensif di lab dengan sinyal defensif. Recruit belajar melihat serangan sebagai pola traffic, bukan hanya event terpisah.

Packet capture sebagai bukti jaringan

PCAP adalah rekaman paket jaringan. Wireshark membantu membuka dan menganalisis PCAP. Setiap paket memiliki layer: frame, Ethernet, IP, TCP/UDP, dan protocol aplikasi seperti HTTP atau DNS. Dalam security, PCAP membantu menjawab: host mana berkomunikasi, protokol apa digunakan, kapan terjadi, dan apakah ada pola tidak wajar.

Filtering adalah keterampilan inti. Display filter seperti HTTP, DNS, IP sumber/tujuan, atau TCP port membantu mempersempit data. Tanpa filter, analyst tenggelam dalam ribuan paket. Namun filter tidak boleh membuat analyst kehilangan konteks. Pola sebelum dan sesudah event sering penting.

Dari attack simulation ke detection

Dalam lab legal, aktivitas seperti scanning, percobaan login gagal, atau request web anomali dapat direkam sebagai traffic. Blue Team melihatnya sebagai sinyal: banyak koneksi ke port berbeda, request dengan pola input tidak biasa, status code error berulang, atau DNS query mencurigakan. Wazuh dapat mengumpulkan log host, memantau file integrity, dan menghasilkan alert berdasarkan rule.

Defensive workflow

Workflow sederhana adalah capture, filter, identify, correlate, dan report. Identify berarti menentukan apa yang terlihat. Correlate berarti menghubungkan PCAP dengan log web server, auth log, atau alert SIEM. Report berarti menulis timeline, indikator, dampak, dan rekomendasi. Analyst yang baik tidak hanya berkata “ada serangan”, tetapi menunjukkan bukti dan konteks.

Skenario lapangan

Dalam simulasi lab, aplikasi Juice Shop menerima banyak request error pada endpoint login. Wireshark menunjukkan pola HTTP POST berulang; Wazuh menerima log failed login; dashboard SIEM membuat alert medium. Defender menambahkan rate limiting, alert threshold, dan review autentikasi.

wireshark lab-traffic.pcapng
