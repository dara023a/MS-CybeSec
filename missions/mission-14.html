Deep Dive Material

Static analysis mencari permission berlebihan, komponen exported, komunikasi tidak aman, penyimpanan data sensitif, hardcoded secrets, konfigurasi network security, dan logika autentikasi yang terlihat dari decompile. JADX membantu membaca struktur kode, MobSF memberi ringkasan otomatis. Hasil otomatis harus divalidasi karena false positive umum terjadi.


Hubungan offensive dan defensive: recruit belajar memahami root cause, dampak, bukti teknis, serta cara mengubah temuan menjadi rekomendasi perbaikan.

O // Textbook Chapter

DEEP MATERIAL NODE
FULL CHAPTER MODE

Android Static Analysis: Membaca APK Tanpa Menjalankannya

Bab ini membahas analisis statis Android secara aman: arsitektur aplikasi, AndroidManifest, komponen, permission, hardcoded secret, insecure storage, dan cara membaca hasil decompile dengan hati-hati.

Android sebagai ekosistem komponen

Aplikasi Android terdiri dari komponen seperti Activity, Service, Broadcast Receiver, dan Content Provider. Komponen ini dideklarasikan dalam AndroidManifest.xml bersama permission, intent-filter, package name, minimum SDK, dan konfigurasi keamanan. Static analysis memeriksa artefak ini tanpa menjalankan aplikasi.

APK sebenarnya adalah paket yang berisi kode, resource, manifest, library native, dan metadata. Tools seperti JADX membantu membaca decompiled source, sedangkan MobSF dapat memberi ringkasan risiko. Namun hasil tools harus divalidasi. Tidak semua temuan otomatis vulnerability; beberapa adalah informational atau false positive.

Risiko yang dicari

Static analysis mencari hardcoded secrets, endpoint API, konfigurasi TLS lemah, exported component yang tidak perlu, permission berlebihan, penyimpanan data sensitif, logging sensitif, dan penggunaan library rentan. Hardcoded secret sangat berisiko karena APK dapat diunduh dan dianalisis. Jika secret memberi akses backend, attacker dapat menyalahgunakannya.

Mitigasi developer

Developer sebaiknya tidak menyimpan secret bernilai tinggi di client. Validasi otorisasi harus tetap dilakukan di server. Gunakan Android Keystore untuk material kriptografi yang cocok, minimalkan permission, nonaktifkan exported component kecuali diperlukan, dan gunakan network security config dengan benar. Data sensitif harus dienkripsi dan tidak dicatat di log.

Skenario lapangan

Tim melakukan review aplikasi internal. Static analysis menemukan base URL staging dan API key di source decompiled. Setelah ditelusuri, API key hanya untuk telemetry non-sensitif, tetapi endpoint staging seharusnya tidak ada di build production. Rekomendasi: pisahkan build config, rotasi key jika perlu, dan tambahkan pemeriksaan CI/CD agar konfigurasi staging tidak masuk production.
