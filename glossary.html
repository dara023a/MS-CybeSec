Cybersecurity Terms

54 TERMS

Authentication

Proses membuktikan identitas pengguna.


Contoh: Login dengan username, password, dan MFA.

Mission 04, 06

Authorization

Proses menentukan hak akses setelah pengguna dikenali.


Contoh: User biasa tidak boleh membuka panel admin.

Mission 06

Endpoint

Alamat fungsi/API yang menerima request.


Contoh: /api/profile adalah endpoint profil.

Mission 04

Request

Pesan dari client ke server.


Contoh: Browser meminta halaman /login.

Mission 04

Response

Balasan server ke client.


Contoh: Server mengirim status 200 dan HTML.

Mission 04

Header

Metadata dalam request/response HTTP.


Contoh: Content-Type menjelaskan format data.

Mission 04

Cookie

Data kecil yang disimpan browser untuk sesi atau preferensi.


Contoh: session_id disimpan sebagai cookie.

Mission 04

Session

Keadaan login yang dipertahankan server/aplikasi.


Contoh: User tetap login saat berpindah halaman.

Mission 04, 06

Hashing

Mengubah data menjadi sidik jari satu arah.


Contoh: Password disimpan sebagai hash bcrypt.

Mission 04

Salting

Menambahkan nilai acak pada password sebelum hashing.


Contoh: Salt mencegah hash sama untuk password sama.

Mission 04

Encryption

Mengubah data agar hanya bisa dibaca dengan kunci.


Contoh: HTTPS mengenkripsi komunikasi.

Mission 04

TLS

Protokol keamanan untuk komunikasi terenkripsi.


Contoh: HTTPS memakai TLS.

Mission 04

JWT

Token berisi klaim yang ditandatangani.


Contoh: JWT dapat membawa user_id dan role.

Mission 04

Base64

Encoding, bukan enkripsi.


Contoh: String terlihat acak tetapi mudah didecode.

Mission 04

Information Disclosure

Kebocoran informasi yang tidak semestinya muncul.


Contoh: Stack trace terlihat di halaman error.

Mission 05

Secret

Nilai sensitif seperti API key atau token.


Contoh: .env berisi secret aplikasi.

Mission 05

IDOR

Akses objek langsung tanpa validasi hak akses memadai.


Contoh: Mengubah ID invoice di lab menampilkan invoice lain.

Mission 06

Broken Access Control

Kegagalan pembatasan hak akses.


Contoh: Endpoint admin bisa diakses user biasa.

Mission 06

Rate Limiting

Pembatasan jumlah request dalam waktu tertentu.


Contoh: Login dibatasi setelah beberapa percobaan gagal.

Mission 06

MFA

Multi-factor authentication.


Contoh: Password ditambah kode OTP.

Mission 06

CSRF

Request tidak diinginkan yang memanfaatkan sesi korban.


Contoh: Aksi sensitif tanpa token CSRF.

Mission 07

SameSite

Atribut cookie untuk membatasi pengiriman lintas situs.


Contoh: SameSite=Lax membantu mencegah CSRF.

Mission 07

MIME Type

Penanda tipe konten file.


Contoh: image/png untuk PNG.

Mission 07

SQL Injection

Input mengubah maksud query database.


Contoh: Parameter pencarian tidak diproses aman.

Mission 08

Prepared Statement

Query dengan parameter terpisah dari perintah.


Contoh: Mencegah input menjadi perintah SQL.

Mission 08

XSS

Script tidak tepercaya berjalan di browser.


Contoh: Komentar di lab merender script.

Mission 09

CSP

Content Security Policy untuk membatasi sumber script.


Contoh: CSP mengurangi dampak XSS.

Mission 09

Clickjacking

Menipu klik pengguna melalui framing/overlay.


Contoh: Tombol penting dibingkai secara tersembunyi.

Mission 09

SSRF

Server dipaksa membuat request ke alamat tidak semestinya.


Contoh: Fitur fetch URL tidak divalidasi aman.

Mission 10

CTF

Latihan legal berbasis tantangan dan flag.


Contoh: picoCTF menyediakan soal pemula.

Mission 11

Reconnaissance

Pengumpulan informasi awal dalam scope legal.


Contoh: Mencatat service lab yang terbuka.

Mission 12

Enumeration

Pendalaman informasi dari service yang ditemukan.


Contoh: Membaca banner service lab.

Mission 12

Foothold

Akses awal pada lab legal.


Contoh: Akses user terbatas di machine latihan.

Mission 12

Privilege Escalation

Meningkatkan hak akses di lab legal karena salah konfigurasi.


Contoh: Dibahas konseptual dan legal.

Mission 12

Scope

Batas target yang boleh diuji.


Contoh: Program hanya mengizinkan domain tertentu.

Mission 13

Rules of Engagement

Aturan pengujian yang disepakati.


Contoh: Tidak boleh DoS atau akses data pengguna.

Mission 13

APK

Paket aplikasi Android.


Contoh: APK berisi manifest dan kode.

Mission 14

AndroidManifest.xml

File konfigurasi utama Android.


Contoh: Menentukan permission dan komponen.

Mission 14

Static Analysis

Analisis tanpa menjalankan aplikasi.


Contoh: Membuka APK dengan JADX.

Mission 14

Dynamic Analysis

Analisis saat aplikasi berjalan.


Contoh: Mengamati request API di emulator lab.

Mission 15

ADB

Android Debug Bridge.


Contoh: Menghubungkan komputer dan emulator.

Mission 15

SSL Pinning

Aplikasi mempercayai sertifikat tertentu.


Contoh: Mencegah proxy tidak sah.

Mission 15

Prompt Injection

Instruksi berbahaya yang memanipulasi model AI.


Contoh: Konten tak tepercaya menyuruh AI mengabaikan aturan.

Mission 16

Hallucination

Output AI yang tampak yakin tetapi salah.


Contoh: AI menyebut referensi yang tidak valid.

Mission 16

PCAP

File rekaman paket jaringan.


Contoh: Dibuka dengan Wireshark.

Mission 17

Packet

Unit data yang dikirim di jaringan.


Contoh: Paket TCP membawa segmen data.

Mission 17

SIEM

Sistem pengumpulan dan korelasi log keamanan.


Contoh: Wazuh dapat dipakai sebagai SIEM.

Mission 18

Threat Hunting

Pencarian proaktif tanda aktivitas mencurigakan.


Contoh: Mencari pola login anomali.

Mission 18

IOC

Indicator of Compromise.


Contoh: IP/domain/hash yang terkait ancaman.

Mission 18

MISP

Platform threat intelligence.


Contoh: Mengelola IOC dan konteks ancaman.

Mission 18

Chain of Custody

Catatan pengelolaan bukti digital.


Contoh: Siapa memegang evidence dan kapan.

Mission 19

Artifact

Jejak digital yang relevan dalam forensik.


Contoh: Log, file, registry, timestamp.

Mission 19

Timeline Analysis

Menyusun urutan kejadian insiden.


Contoh: Menentukan kapan akses awal terjadi.

Mission 19

ATS

Applicant Tracking System.


Contoh: CV harus mudah dibaca sistem rekrutmen.
